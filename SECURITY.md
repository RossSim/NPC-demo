# Security

Report vulnerabilities **privately** with [GitHub Security Advisories](https://github.com/RossSim/NPC-demo/security/advisories/new) on this repository. Do not open a public issue for a security report.

This project is a Unity host, not a network service. Useful reports include secret leaks in the repo, supply-chain issues in CI, or unsafe handling if a game loads persist JSON or catalog JSON from untrusted players.
